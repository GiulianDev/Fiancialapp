# Development Rules & Context

## Tech Stack
- **Frontend:** React, Vite, TypeScript
- **Styling:** Tailwind CSS
- **Patterns:** Functional Components, Hooks, Strict Typing (no `any`)

## UI/UX Guidelines
- **Style:** Modern, Minimalist.
- **Effects:** Heavy use of Glassmorphism (frosted glass effects).
- **Palette:** Neutral tones with Electric Blue and Purple accents.
- **Consistency:** Ensure responsive layouts and accessible components.

## LLM Interaction Rules
- **Conciseness:** Do not provide verbose explanations unless explicitly requested.
- **Code Output:** Show only the modified portions of the code using placeholders (e.g., `// ... existing code ...`).
- **Accuracy:** Always verify types before suggesting changes.
- **Language:** Respond in Italian, but keep technical terms and code comments in English/Italian as appropriate.
